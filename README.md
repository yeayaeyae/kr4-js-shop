# КР №4 — интерактивный TechStore на JavaScript

**Студент:** Кигози Елисей Маликовчи · **Группа:** ЭФБО-13-25

Интерактивная многостраничная версия магазина. Основа — адаптивный HTML/CSS проект КР №3.

## Запуск и страницы

Откройте `index.html` напрямую или через Live Server. Страницы: главная, каталог, товар, корзина, заказ, контакты.

## Реализовано

- Единый массив из 9 товаров в `js/data.js` с `id`, названием, категорией, ценой и наличием.
- Построение каталога через DOM-методы `createElement`, `textContent`, `append`; поиск, фильтр категории и сортировка. Пользовательские строки не вставляются через `innerHTML`.
- Корзина сохраняется в `localStorage`, поддерживает увеличение, уменьшение и удаление товара, показывает общую сумму.
- Проверка формы и сообщения об ошибках или успешной отправке выводятся рядом с формой, не через `alert()`.
- Мобильное меню и кнопки добавления используют `addEventListener` и делегирование событий.

## Файлы JavaScript

`data.js` — каталог данных и API корзины; `catalog.js` — поиск/фильтрация/сортировка и построение карточек; `product.js` — карточка товара и характеристики; `cart.js` — отображение корзины; `validation.js` — обработка форм; `main.js` — меню, модальное окно и счётчик корзины.

## Самостоятельные доработки

Корзина с сохранением между страницами и пересчётом суммы; доступные сообщения статуса; изображения с `srcset`; мобильное меню; понятное пустое состояние и блокировка отсутствующих товаров.
